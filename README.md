# Catálogo de Cílios — Base

Esta é a primeira base do sistema.

## O que já funciona nesta versão

- Catálogo de procedimentos
- Fotos/resultados
- Preços e duração
- Avaliações de exemplo
- Busca de procedimentos
- Botão "Quero esse"
- Registro automático do pedido
- Mensagem pronta para WhatsApp
- Painel administrativo de demonstração
- Contagem de pedidos
- Status pendente/confirmado/cancelado
- Cancelamento manual
- Configuração de nome e WhatsApp
- SQL inicial para Supabase

## Teste

Abra `index.html`.

Painel: `admin.html`

Senha provisória: `1234`

## Importante

Esta versão usa `localStorage` apenas para prototipagem.
A próxima etapa é conectar o Supabase, autenticação/whitelist, banco real, Storage para fotos e agenda.

Não use a senha 1234 em produção.
